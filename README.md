# Reelify Pro — página de vendas

Página de vendas e downloads do Reelify Pro (Windows e Mac) e do Reelify Plug para o Adobe Premiere Pro.

- Página: `index.html` (publicada pelo GitHub Pages)
- Instaladores: anexados aos [Releases](../../releases). Os botões da página apontam para `releases/latest/download/...`, então sempre baixam a versão mais nova.
